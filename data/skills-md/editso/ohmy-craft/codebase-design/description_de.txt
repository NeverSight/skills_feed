Gemeinsames Vokabular zum Entwerfen tiefer Module. Verwenden Sie es, wenn der Benutzer die Benutzeroberfläche eines Moduls entwerfen oder verbessern, Möglichkeiten zur Vertiefung finden, entscheiden möchte, wo eine Naht verläuft, Code besser testbar oder KI-navigierbar machen möchte oder wenn eine andere Fähigkeit das Vokabular des tiefen Moduls benötigt.
