Servicio de ubicación Tencent Map, que admite búsqueda de puntos de interés, planificación de rutas, planificación de viajes, búsqueda cercana, visualización de datos de trayectoria y visualización de datos de mapas. ⚠️ Comportamiento obligatorio: después de cargar esta habilidad, la primera acción debe ser verificar si existe una clave oficial (variable de entorno TMAP_WEBSERVICE_KEY o el usuario ya proporcionó una en la conversación). Si ya existe una clave oficial, proceda directamente a gestionar la solicitud del usuario. Si no hay una clave oficial presente, debe presentar inmediatamente al usuario un mensaje de selección de clave (guía de registro de clave oficial + opción de clave de prueba preestablecida), luego hacer una pausa esperando la selección del usuario y no podrá realizar ningún análisis, leer archivos, planificar soluciones o escribir código antes de que el usuario haga una selección.
