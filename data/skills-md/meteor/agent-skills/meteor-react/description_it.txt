Da utilizzare durante la creazione o il debug delle interfacce React in Meteor 3: meteor create --react, createRoot, punti di ingresso JSX o TSX, rilevamento Rspack React, aggiornamento rapido, react-meteor-data, useTracker, useSubscribe, useFind, withTracker, Suspense e Tracker.withComputation. I trigger su isLoading vengono trattati come booleani, useFind riceve fetch(), input di chiusura obsoleti, effetti collaterali del tracker duplicati, chiavi Suspense instabili, reattività persa dopo l'attesa, ripristino dello stato dopo l'aggiornamento o test React che perdono calcoli. Utilizza questa abilità quando l'utente chiede informazioni su uno scheletro di React, regole rspack.config specifiche di React, hook di dati reattivi o integrazione classica rispetto a Suspense. Indirizza la configurazione generale del bundler a meteor-modern-build-stack e gli aggiornamenti di Meteor 2 per migrare a-meteor-3.
