يُستخدم عند إنشاء واجهات React أو تصحيح أخطاءها في Meteor 3: meteor create --react، أو createRoot، أو نقاط إدخال JSX أو TSX، واكتشاف Rspack React، والتحديث السريع، وreact-meteor-data، وuseTracker، وuseSubscribe، وuseFind، وwithTracker، وSuspense، وTracker.withComputation. يتم التعامل مع المشغلات الموجودة على isLoading على أنها منطقية، أو useFind المتلقي fetch()، أو مدخلات الإغلاق التي لا معنى لها، أو الآثار الجانبية المتعقبة المكررة، أو مفاتيح التعليق غير المستقرة، أو التفاعل المفقود بعد الانتظار، أو إعادة تعيين الحالة بعد التحديث، أو اختبارات React للحسابات المسربة. استخدم هذه المهارة عندما يسأل المستخدم عن هيكل React، أو قواعد rspack.config الخاصة بـ React، أو خطافات البيانات التفاعلية، أو التكامل الكلاسيكي مقابل Suspense. قم بتوجيه تكوين المجمع العام إلى Meteor-modern-build-stack وترقيات Meteor 2 إلى migrate-to-meteor-3.
