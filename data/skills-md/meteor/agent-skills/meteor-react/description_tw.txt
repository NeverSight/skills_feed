在 Meteor 3 中建置或偵錯 React 介面時使用：meteor create --react、createRoot、JSX 或 TSX 入口點、Rspack React 偵測、Fast Refresh、react-meteor-data、useTracker、useSubscribe、useFind、withTracker、Suspense 和 Tracker.with.with。觸發 isLoading 被視為布林值、useFind 接收 fetch()、過時的閉包輸入、重複的追蹤器副作用、不穩定的 Suspense 鍵、等待後失去反應性、刷新後狀態重置或 React 測試洩漏計算。當使用者詢問 React 框架、特定於 React 的 rspack.config 規則、反應式資料掛鉤或經典與 Suspense 整合時，請使用此技能。將通用捆綁器配置路由至meteor-modern-build-stack，將Meteor 2 升級路由至migrate-to meteor-3。
