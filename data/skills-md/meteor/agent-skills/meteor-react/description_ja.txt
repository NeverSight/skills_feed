Meteor 3 で React インターフェイスを構築またはデバッグするときに使用します: meteor create --react、createRoot、JSX または TSX エントリ ポイント、Rspack React 検出、Fast Refresh、react-meteor-data、useTracker、useSubscribe、useFind、withTracker、Suspense、および Tracker.withComputation。 isLoading がブール値として扱われる場合、useFind が fetch() を受信する場合、古いクロージャ入力、重複したトラッカーの副作用、不安定な Suspense キー、待機後の反応性の喪失、リフレッシュ後の状態リセット、または React テストの計算リークが発生した場合にトリガーされます。このスキルは、ユーザーが React スケルトン、React 固有の rspack.config ルール、リアクティブ データ フック、またはクラシックとサスペンスの統合について尋ねたときに使用します。一般的なバンドラー構成を meteor-modern-build-stack にルーティングし、Meteor 2 のアップグレードを merge-to-meteor-3 にルーティングします。
