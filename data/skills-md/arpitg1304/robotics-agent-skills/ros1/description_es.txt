Mejores prácticas, patrones de diseño y errores comunes para el desarrollo de ROS1 (Robot Operating System 1). Utilice esta habilidad al crear nodos, paquetes, archivos de inicio o depurar sistemas ROS1. Se activa cada vez que el usuario menciona ROS1, catkin, rospy, roscpp, roslaunch, roscore, rostopic, tf, actionlib, tipos de mensajes, servicios o cualquier middleware robótico de la era ROS1. También activa la migración de código ROS1 a ROS2, el mantenimiento de sistemas ROS1 heredados o la construcción de puentes ROS1-ROS2. Cubre espacios de trabajo catkin, nodelets, reconfiguración dinámica, pluginlib y el ecosistema ROS1 completo.
