Best Practices, Entwurfsmuster und häufige Fallstricke bei der Entwicklung von ROS1 (Robot Operating System 1). Nutzen Sie diese Fähigkeit beim Erstellen von ROS1-Knoten, Paketen, Startdateien oder beim Debuggen von ROS1-Systemen. Wird immer dann ausgelöst, wenn der Benutzer ROS1, catkin, rospy, roscpp, roslaunch, roscore, rostopic, tf, actionlib, Nachrichtentypen, Dienste oder eine beliebige Robotik-Middleware aus der ROS1-Ära erwähnt. Auch Auslöser für die Migration von ROS1-Code zu ROS2, die Wartung älterer ROS1-Systeme oder den Aufbau von ROS1-ROS2-Brücken. Deckt Catkin-Arbeitsbereiche, Nodelets, dynamische Neukonfiguration, Pluginlib und das gesamte ROS1-Ökosystem ab.
