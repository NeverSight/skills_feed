أفضل الممارسات وأنماط التصميم والمزالق الشائعة لتطوير ROS1 (نظام تشغيل الروبوت 1). استخدم هذه المهارة عند إنشاء عقد ROS1 أو الحزم أو تشغيل الملفات أو تصحيح أخطاء أنظمة ROS1. يتم تشغيله عندما يذكر المستخدم ROS1، أو catkin، أو rospy، أو roscpp، أو roslaunch، أو roscore، أو rostopic، أو tf، أو actionlib، أو أنواع الرسائل، أو الخدمات، أو أي برامج وسيطة للروبوتات من عصر ROS1. قم أيضًا بتشغيل ترحيل كود ROS1 إلى ROS2 أو الحفاظ على أنظمة ROS1 القديمة أو إنشاء جسور ROS1-ROS2. يغطي مساحات عمل catkin والعقد وإعادة التكوين الديناميكي والمكونات الإضافية والنظام البيئي ROS1 الكامل.
