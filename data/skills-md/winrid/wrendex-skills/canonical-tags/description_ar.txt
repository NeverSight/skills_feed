تدقيق علامات rel=canonical عبر الموقع: العناوين الأساسية التي تشير إلى عمليات إعادة التوجيه، أو صفحات 404 أو الصفحات غير القابلة للفهرسة، وعدم تطابق http/https، والصفحات المتعارف عليها بدون روابط واردة. يُستخدم عندما يقول المستخدم "العلامات الأساسية"، أو "التحديد الأساسي"، أو "rel=canonical"، أو "عنوان URL الأساسي الخاطئ"، أو "أي إصدار من هذه الصفحة يقوم بفهرسة Google".
