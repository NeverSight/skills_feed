Используйте, когда пользователь передает репозиторий плагинов dsh (или реальную фиксацию миграции/коридор версий) и хочет, чтобы его опыт обновления был извлечен в одно задание экзамена производительности Harbour с автоматической оценкой — создайте задачи/<id>/ (фикстура + инструкция.md + задача.toml + судья.mjs + решение), которые при запуске порта могут получить оценку 0–1 и которые включаются в набор тестов dsh-plugin-upgrade-skill; также применимо для преобразования существующих карточек версий (references/v*.md) в исполняемые экзаменационные задания. Не для написания карт апгрейда; не для запуска теста.
