Verwenden Sie diese Option, wenn Sie eine schwere Browser-Abhängigkeit (Diagramm-/Diagramm-Renderer wie Mermaid, Code-Editoren, große, an Wasm angrenzende Bibliotheken) zu einem leichten DSH-Web-Plugin hinzufügen, das klein bleiben muss, wenn Sie einen Lazy-Loaded-Block über eine Host-Route verbinden, wenn der Lazy-Import zeitweise fehlschlägt oder zurückfällt, oder wenn Sie nicht vertrauenswürdiges Markup (SVG/HTML) rendern, das durch eine solche Abhängigkeit erzeugt wird.
