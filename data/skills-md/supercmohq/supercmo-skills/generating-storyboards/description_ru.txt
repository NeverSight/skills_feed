Генерирует листы раскадровки для видео — по одному изображению на клип, панели подряд, на каждой панели одно действие. Разделяет каждый клип на панели, затем строит листы по одному, каждый из которых использует предыдущий в качестве эталона, поэтому человек и продукт остаются согласованными, за исключением тех случаев, когда история намеренно меняет их. Используйте, когда продолжительность и сюжет видео определены, и перед анимацией нужны листы. Не для неподвижного изображения как такового — его следует создавать с помощью генератора изображений.
