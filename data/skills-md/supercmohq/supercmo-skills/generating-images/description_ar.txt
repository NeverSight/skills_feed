اقرأ دائمًا هذه المهارة قبل إنشاء أي صورة أو تحريرها، أو استدعاء image_generate - تحويل النص إلى صورة أو صورة إلى صورة، بسيطة أو معقدة. يحول ملخصًا نصيًا، مسترشدًا بشكل اختياري بالصور المرجعية (حرف، نمط يجب اتباعه، صورة موجودة لتحريرها)، إلى صورة ثابتة. يحلل النية، ويوجه إلى أفضل نموذج، ويبني الموجه. يُستخدم عندما يطلب المستخدم إنشاء صورة أو إنشائها أو تصميمها أو تحريرها - باستثناء التصوير الفوتوغرافي التجاري لمنتج يتم بيعه، والذي ينتمي إلى إنشاء صور المنتج.
