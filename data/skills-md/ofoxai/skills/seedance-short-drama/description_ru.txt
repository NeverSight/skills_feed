Создайте один реалистичный кадр короткометражной драмы с человеческими диалогами на основе сценария или описания сцены с помощью видео API Ofox (Seedance 2.5) — записывает подсказку для создания кадра (внешний вид персонажа, цитируемый диалог, временные метки для сцены), показывает смету затрат, затем вызывает ofox-video-core для отправки, опроса, загрузки и отчета о реальной стоимости. Используйте, когда пользователь просит превратить бит сценария в видео, например. «создайте третью сцену этого сценария, два персонажа разговаривают, 15 секунд», «сделайте вертикальный короткометражный клип, в котором эти двое спорят на кухне», «превратите этот диалог в 12-секундное видео» или «дайте мне реалистичный короткометражный кадр, в котором пара расстается на вокзале». Не используйте для тихих снимков продукта/бренда (см. рекламный креатив) или для чего-либо, не связанного с людьми/диалогами.
