Превратите отрывок из романа/сценария в раскадровку в стиле аниме или манги с помощью API изображений и видео Ofox — генерирует одно эталонное изображение персонажа с помощью ofox-image-core, затем повторно использует это же самое изображение как `--frame-first-image` для каждого кадра этого персонажа с помощью ofox-video-core для обеспечения реальной визуальной согласованности вместо того, чтобы полагаться только на повторяющееся текстовое описание. Используйте, когда пользователь просит превратить отрывок истории в аниме-видео, например «превратить этот отрывок из романа в аниме-видео», «сделать раскадровку этой сцены в стиле аниме», «создать кадр манга-драмы с этим персонажем» или «превратить эту главу в короткометражку аниме с одним и тем же персонажем в каждом кадре». Не используйте для сцен с реалистичными человеческими диалогами без стиля аниме/манги (см. короткометражную драму «посевной материал»), немых кадров продукта/бренда (см. рекламный ролик «посевной материал») или простых кадров из каталога (см. видеоролик «посевной продукт»).
