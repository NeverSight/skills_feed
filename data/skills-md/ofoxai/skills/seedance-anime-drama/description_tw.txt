使用 Ofox 圖像和視頻 API 將小說/劇本摘錄轉換為動漫或漫畫風格的故事板鏡頭 — 使用 ofox-image-core 生成一個角色參考圖像，然後通過 ofox-video-core 在該角色的每個鏡頭中重複使用該完全相同的圖像作為“--frame-first-image”，以實現真正的視覺一致性，而不是僅僅依賴重複的文本描述。當用戶要求將故事摘錄轉換為動漫影片時使用，例如「將這部小說摘錄變成動漫影片」、「製作該場景的動漫風格故事板剪輯」、「產生與該角色相關的漫畫鏡頭」或「將本章變成每個鏡頭中都有相同角色的動漫短片」。請勿用於沒有動漫/漫畫風格的真實人類對話場景（請參閱seedance-short-drama）、無聲產品/品牌鏡頭（請參閱seedance-ad-creative）或普通目錄鏡頭（請參閱seedance-product-video）。
