使用 Ofox 图像和视频 API 将小说/剧本摘录转换为动漫或漫画风格的故事板镜头 — 使用 ofox-image-core 生成一个角色参考图像，然后通过 ofox-video-core 在该角色的每个镜头中重复使用该完全相同的图像作为“--frame-first-image”，以实现真正的视觉一致性，而不是仅仅依赖重复的文本描述。当用户要求将故事摘录转换为动漫视频时使用，例如“将这部小说摘录变成动漫视频”、“制作该场景的动漫风格故事板剪辑”、“生成与该角色相关的漫画镜头”或“将本章变成每个镜头中都有相同角色的动漫短片”。请勿用于没有动漫/漫画风格的真实人类对话场景（请参阅seedance-short-drama）、无声产品/品牌镜头（请参阅seedance-ad-creative）或普通目录镜头（请参阅seedance-product-video）。
