Behandeln Sie Bilder mit ImageMagick (Magick) – lesen Sie Metadaten, ändern Sie die Größe, beschneiden Sie sie, drehen Sie sie, konvertieren Sie das Format, kombinieren Sie Bilder (nebeneinander oder in Rastern mit Montage), überlagern Sie Logos/Wasserzeichen und komprimieren Sie sie vor dem Senden verlustfrei mit Oxipng. Verwenden Sie diese Funktion, wenn der Benutzer ein Bild zur Verarbeitung sendet, wenn Sie ein Bild zur Übermittlung erstellen oder bevor Sie ein Bild an eine Nachricht anhängen oder hochladen. Wenn Sie zunächst komprimieren, bleiben die Übertragungen schnell und die Token niedrig. Kerndisziplin: Vor der Übermittlung immer komprimieren, dem Benutzer niemals lokale Dateipfade offenlegen und nicht öffnen (wenn ein Tool fehlt oder ein Schrittfehler auftritt, das Original unverändert weiterleiten; die Aufgabe niemals blockieren).
