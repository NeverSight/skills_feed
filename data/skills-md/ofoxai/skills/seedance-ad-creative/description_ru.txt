Создайте кинематографический рекламный ролик бренда/продукта на основе описания продукта или фотографии с помощью видео API Ofox (Seedance 2.5) — записывает подсказку для создания кадра (кадр продукта, язык камеры, тон бренда), показывает смету затрат, затем вызывает ofox-video-core для отправки, опроса, загрузки и сообщения о реальной стоимости. Используйте, когда пользователь запрашивает рекламный продукт или видео бренда, например «дайте этому флакону духов 10-секундную кинематографическую рекламу бренда», «сделайте рекламу наших новых кроссовок», «превратите фотографию этого продукта в главное видео для целевой страницы» или «Мне нужно 15-секундное видео бренда с медленным вращением вокруг флакона». Не используйте для сцен, основанных на диалогах, когда люди разговаривают (см. короткометражную драму).
