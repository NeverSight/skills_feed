Gemeinsame Ausführungsschicht für die Ofox-Videogenerierungs-API (api.ofox.ai) – erstellt einen Videoauftrag, fragt ihn bis zur Fertigstellung ab, lädt die fertige MP4-Datei von einer dauerhaften CDN-URL herunter und meldet die tatsächlichen Kosten. Hierbei handelt es sich um einen Bibliotheks-Skill und nicht um einen eigenständigen, benutzerorientierten Skill. Er wird durch Szenario-Skills wie „Seedance-Short-Drama“, „Seedance-Ad-Creative“ und „Seedance-Product-Video“ aufgerufen, die Modell-/Eingabeaufforderungs-/Auflösungsoptionen für einen bestimmten Anwendungsfall erstellen und dann das Skript dieses Skills aufrufen, anstatt die API-Aufrufe erneut zu implementieren. Laden Sie diesen Skill nur dann direkt, wenn ein Benutzer die Ofox-Video-API explizit benennt, sie mit bestimmten Low-Level-Parametern aufrufen möchte oder einen hängengebliebenen oder fehlgeschlagenen Ofox-Videojob anhand der Job-ID debuggen/fortsetzen möchte. Verwenden Sie für eine einfache Szenarioanforderung („Mach mir eine kurze Dramaszene“, „Generiere einen filmischen Werbeclip“) stattdessen den entsprechenden Szenario-Skill, der wiederum von diesem abhängt.
