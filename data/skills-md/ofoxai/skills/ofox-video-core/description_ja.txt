Ofox ビデオ生成 API (api.ofox.ai) の共有実行レイヤー — ビデオ ジョブを作成し、完了するまでポーリングし、完成した MP4 を永続的な CDN URL からダウンロードし、実際のコストをレポートします。これはライブラリ スキルであり、スタンドアロンのユーザー向けスキルではありません。これは、seedance-short-drama、seedance-ad-creative、seedance-product-video などのシナリオ スキルによって呼び出されます。これらのスキルは、特定のユースケース向けのモデル/プロンプト/解像度の選択肢を構築し、API 呼び出しを再実装するのではなく、このスキルのスクリプトを呼び出します。このスキルを直接ロードするのは、ユーザーが Ofox ビデオ API に明示的に名前を付けるか、特定の低レベル パラメーターで呼び出すように要求するか、スタックまたは失敗した Ofox ビデオ ジョブをジョブ ID でデバッグ/再開するように要求する場合に限られます。単純なシナリオ リクエスト (「短いドラマ シーンを作成してください」、「映画の広告クリップを生成してください」) の場合は、代わりに関連するシナリオ スキルを使用します (それ自体がこのスキルに依存します)。
