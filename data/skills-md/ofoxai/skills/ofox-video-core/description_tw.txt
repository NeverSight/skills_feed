Ofox 視訊產生 API (api.ofox.ai) 的共用執行層 — 建立一個視訊作業，輪詢其完成，從持久 CDN URL 下載完成的 mp4，並報告實際成本。這是一項庫技能，而不是獨立的面向用戶的技能 - 它由場景技能（例如seedance-short-drama、seedance-ad-creative 和seedance-product-video）調用，這些技能為特定用例構建模型/提示/分辨率選擇，然後調用該技能的腳本，而不是重新實現API 調用。只有當使用者明確命名 Ofox 視訊 API、要求使用特定的低階參數呼叫它或要求透過作業 ID 調試/恢復卡住或失敗的 Ofox 視訊作業時，才直接加載此技能 - 對於簡單的場景請求（“為我製作一個簡短的戲劇場景”、“生成電影廣告剪輯”），請使用相關的場景技能，該技能本身取決於此技能。
