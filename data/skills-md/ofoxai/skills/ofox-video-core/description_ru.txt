Общий уровень выполнения для API создания видео Ofox (api.ofox.ai) — создает задание видео, опрашивает его до завершения, загружает готовый mp4 из постоянного URL-адреса CDN и сообщает реальную стоимость. Это библиотечный навык, а не автономный навык, ориентированный на пользователя — он вызывается такими сценарными навыками, как «посев-короткая драма», «посев-реклама-креатив» и «посев-продукт-видео», которые создают варианты модели/подсказки/разрешения для конкретного варианта использования, а затем вызывают сценарий этого навыка, а не повторно реализуют вызовы API. Загружайте этот навык напрямую только тогда, когда пользователь явно называет видео API Ofox, просит вызвать его с определенными параметрами низкого уровня или просит отладить/возобновить зависшее или невыполненное видео задание Ofox по идентификатору задания — для простого запроса сценария («сделайте мне короткую драматическую сцену», «создайте кинематографический рекламный ролик») вместо этого используйте соответствующий навык сценария, который сам зависит от этого.
