Capa de ejecución compartida para la API de generación de video de Ofox (api.ofox.ai): crea un trabajo de video, lo sondea hasta su finalización, descarga el mp4 terminado desde una URL CDN persistente e informa el costo real. Esta es una habilidad de biblioteca, no una habilidad independiente orientada al usuario: se invoca mediante habilidades de escenario como seedance-short-drama, seedance-ad-creative y seedance-product-video, que crean opciones de modelo/mensaje/resolución para un caso de uso específico y luego llaman al script de esta habilidad en lugar de volver a implementar las llamadas API. Cargue esta habilidad directamente solo cuando un usuario nombra explícitamente la API de video de Ofox, solicita llamarla con parámetros específicos de bajo nivel o solicita depurar/reanudar un trabajo de video de Ofox atascado o fallido por ID de trabajo; para una solicitud de escenario simple ("hazme una escena dramática corta", "genera un clip de anuncio cinematográfico"), usa la habilidad de escenario relevante en su lugar, que a su vez depende de ésta.
