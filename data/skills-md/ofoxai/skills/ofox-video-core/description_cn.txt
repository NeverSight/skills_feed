Ofox 视频生成 API (api.ofox.ai) 的共享执行层 — 创建一个视频作业，轮询其完成，从持久 CDN URL 下载完成的 mp4，并报告实际成本。这是一项库技能，而不是独立的面向用户的技能 - 它由场景技能（例如seedance-short-drama、seedance-ad-creative 和seedance-product-video）调用，这些技能为特定用例构建模型/提示/分辨率选择，然后调用该技能的脚本，而不是重新实现API 调用。仅当用户明确命名 Ofox 视频 API、要求使用特定的低级参数调用它或要求通过作业 ID 调试/恢复卡住或失败的 Ofox 视频作业时，才直接加载此技能 - 对于简单的场景请求（“为我制作一个简短的戏剧场景”、“生成电影广告剪辑”），请使用相关的场景技能，该技能本身取决于此技能。
