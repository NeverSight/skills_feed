Ofox 图像生成 API (api.ofox.ai) 的共享执行层 — 验证客户端参数，发送一个同步文本到图像请求，对结果进行 Base64 解码，将其保存到文件中，并报告实际使用令牌计数和计算出的美元成本。这是一项库技能，而不是一个独立的面向用户的技能 - 它旨在由场景技能（例如视频管道的字符参考表生成器）调用，为特定用例构建模型/提示/大小选择，然后调用该技能的脚本，而不是重新实现 API 调用。仅当用户明确命名 Ofox 图像 API、要求使用特定的低级参数调用它或要求调试失败的 Ofox 图像生成请求时，才直接加载此技能 - 对于尚无可用场景技能的普通“生成...的图像”请求，这是直接使用的正确技能。
