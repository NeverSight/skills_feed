Gemeinsame Ausführungsschicht für die Ofox-Bildgenerierungs-API (api.ofox.ai) – validiert Parameter clientseitig, sendet eine synchrone Text-zu-Bild-Anfrage, dekodiert das Ergebnis mit Base64, speichert es in einer Datei und meldet die tatsächliche Anzahl der Nutzungstokens und die berechneten Dollarkosten. Hierbei handelt es sich um einen Bibliotheks-Skill, nicht um einen eigenständigen, benutzerorientierten Skill. Er soll von Szenario-Skills (z. B. einem Charakter-Referenzblatt-Generator für eine Video-Pipeline) aufgerufen werden, die Modell-/Eingabeaufforderungs-/Größenoptionen für einen bestimmten Anwendungsfall erstellen und dann das Skript dieses Skills aufrufen, anstatt die API-Aufrufe erneut zu implementieren. Laden Sie diesen Skill nur dann direkt, wenn ein Benutzer die Ofox-Bild-API explizit benennt, sie mit bestimmten Low-Level-Parametern aufrufen möchte oder eine fehlgeschlagene Ofox-Bildgenerierungsanforderung debuggen möchte – für eine einfache Anfrage „Generieren Sie ein Bild von …“, für die noch kein Szenario-Skill verfügbar ist, ist dies der richtige Skill, den Sie direkt verwenden können.
