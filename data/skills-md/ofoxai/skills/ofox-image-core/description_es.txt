Capa de ejecución compartida para la API de generación de imágenes de Ofox (api.ofox.ai): valida los parámetros del lado del cliente, envía una solicitud sincrónica de texto a imagen, decodifica en base64 el resultado, lo guarda en un archivo e informa los recuentos de tokens de uso real y el costo en dólares calculado. Esta es una habilidad de biblioteca, no una habilidad independiente orientada al usuario; está destinada a ser invocada por habilidades de escenario (por ejemplo, un generador de hojas de referencia de personajes para un canal de video) que crea opciones de modelo/mensaje/tamaño para un caso de uso específico y luego llama al script de esta habilidad en lugar de volver a implementar las llamadas API. Cargue esta habilidad directamente solo cuando un usuario nombra explícitamente la API de imágenes de Ofox, solicita llamarla con parámetros específicos de bajo nivel o solicita depurar una solicitud fallida de generación de imágenes de Ofox; para una solicitud simple de "generar una imagen de..." sin una habilidad de escenario disponible todavía, esta es la habilidad correcta para usar directamente.
