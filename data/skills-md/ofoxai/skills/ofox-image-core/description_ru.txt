Общий уровень выполнения для API создания изображений Ofox (api.ofox.ai) — проверяет параметры на стороне клиента, отправляет один синхронный запрос преобразования текста в изображение, декодирует результат в base64, сохраняет его в файл и сообщает о реальном количестве токенов использования и вычисленной стоимости в долларах. Это библиотечный навык, а не автономный навык, ориентированный на пользователя — он предназначен для вызова сценарными навыками (например, генератором справочных таблиц символов для видеоконвейера), которые создают варианты модели/подсказки/размера для конкретного варианта использования, а затем вызывают сценарий этого навыка, а не повторно реализуют вызовы API. Загружайте этот навык напрямую только тогда, когда пользователь явно называет API изображения Ofox, просит вызвать его с определенными параметрами низкого уровня или просит отладить неудачный запрос на создание изображения Ofox — для простого запроса «создать изображение...» без доступного навыка сценария это правильный навык, который можно использовать напрямую.
