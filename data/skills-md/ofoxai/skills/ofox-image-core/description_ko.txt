Ofox 이미지 생성 API(api.ofox.ai)를 위한 공유 실행 레이어 — 클라이언트 측 매개변수의 유효성을 검사하고, 하나의 동기식 텍스트-이미지 요청을 보내고, 결과를 base64로 디코딩하고, 이를 파일에 저장하고, 실제 사용량 토큰 수와 계산된 달러 비용을 보고합니다. 이는 독립 실행형 사용자 지향 기술이 아닌 라이브러리 기술입니다. 특정 사용 사례에 대한 모델/프롬프트/크기 선택 사항을 구축한 다음 API 호출을 다시 구현하는 대신 이 기술의 스크립트를 호출하는 시나리오 기술(예: 비디오 파이프라인을 위한 문자 참조 시트 생성기)에 의해 호출됩니다. 사용자가 Ofox 이미지 API의 이름을 명시적으로 지정하거나 특정 하위 수준 매개 변수를 사용하여 호출하도록 요청하거나 실패한 Ofox 이미지 생성 요청을 디버깅하도록 요청하는 경우에만 이 기술을 직접 로드합니다. 아직 시나리오 기술을 사용할 수 없는 일반 "...의 이미지 생성" 요청의 경우 직접 사용하기에 적합한 기술입니다.
