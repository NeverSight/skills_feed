Ofox 映像產生 API (api.ofox.ai) 的共用執行層 — 驗證用戶端參數，傳送一個同步文字到映像請求，對結果進行 Base64 解碼，將其儲存到檔案中，並報告實際使用令牌計數和計算出的美元成本。這是一項庫技能，而不是一個獨立的面向用戶的技能 - 它旨在由場景技能（例如視頻管道的字符參考表生成器）調用，為特定用例構建模型/提示/大小選擇，然後調用該技能的腳本，而不是重新實現 API 呼叫。只有當使用者明確命名 Ofox 映像 API、要求使用特定的低階參數呼叫它或要求偵錯失敗的 Ofox 圖片產生請求時，才直接載入此技能 - 對於尚無可用場景技能的普通「生成...的圖片」請求，這是直接使用的正確技能。
