Ofox 画像生成 API (api.ofox.ai) の共有実行層 — クライアント側でパラメーターを検証し、1 つの同期テキストから画像へのリクエストを送信し、結果を Base64 デコードしてファイルに保存し、実際の使用量トークン数と計算されたドルコストをレポートします。これはライブラリ スキルであり、スタンドアロンのユーザー向けスキルではありません。これは、API 呼び出しを再実装するのではなく、特定のユースケースに合わせてモデル/プロンプト/サイズの選択を構築し、このスキルのスクリプトを呼び出すシナリオ スキル (ビデオ パイプラインのキャラクター リファレンス シート ジェネレーターなど) によって呼び出されることを目的としています。このスキルは、ユーザーが Ofox 画像 API に明示的に名前を付ける場合、特定の低レベル パラメーターを使用して呼び出すように要求する場合、または失敗した Ofox 画像生成リクエストのデバッグを要求する場合にのみ直接ロードします。シナリオ スキルがまだ利用できない単純な「... の画像を生成する」リクエストの場合、これは直接使用するのに適したスキルです。
