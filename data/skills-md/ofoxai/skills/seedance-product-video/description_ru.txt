Создайте чистое видео о продукте для электронной коммерции в стиле каталога на основе реальной фотографии продукта (или, что менее надежно, текстового описания) с помощью видео API Ofox (Seedance 2.5) — записывает простой фон с буквальной точностью (точное описание продукта, простое движение поворотного стола/орбиты, отсутствие драматической кинематографии), показывает смету затрат, затем вызывает ofox-video-core для отправки, опроса, загрузки и отчета о реальной стоимости. Используйте, когда пользователь просит превратить фотографию продукта в кадры каталога/списка, например. «превратите это фото продукта в витрину на белом фоне на 360 градусов», «превратите это фото в видео о продукте на белом фоне», «сделайте чистое видео с проигрывателем этого товара» или «дайте мне 5-секундное ротационное видео этого продукта на белом фоне для моего объявления». Не используйте для кинематографической рекламы бренда/настроения (см. рекламный ролик) или для чего-либо, связанного с людьми/диалогами (см. короткометражная драма).
