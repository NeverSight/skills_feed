قم بتصدير آثار OpenTelemetry الأولية من تطبيق الذكاء الاصطناعي إلى مرصد Confident AI. TRIGGER عندما يريد المستخدم إرسال آثار/امتدادات OpenTelemetry أو OTLP من تطبيق LLM أو وكيل أو خط أنابيب RAG أو chatbot إلى Confident AI؛ تكوين نقطة نهاية Confident AI OTLP؛ قم بتعيين سماتconfed.span.* أوconfidence.trace.*؛ تصدير آثار تطبيقات الذكاء الاصطناعي بدون حزمة Python العميقة؛ قم بتوصيل OTLPSpanExporter أو OpenTelemetry Collector أو OTel SDK المحايدة للبائع إلى Confident AI؛ أو اختر نقطة نهاية OTLP بين الولايات المتحدة والاتحاد الأوروبي. حيادية اللغة: الآلية هي مفاتيح سمات OTLP بالإضافة إلى نقطة نهاية المصدر. لا تقم بالبدء في إنشاء مجموعات تقييم DeepEval pytest أو مجموعات البيانات أو الذهبيات أو المقاييس أو التشغيل التجريبي العميق (استخدم مهارة "deepeval")؛ للأدوات باستخدام ديكور @observe الخاص بـ DeepEval SDK أو تكاملات إطار العمل (استخدم مهارة "deepeval-tracing") ؛ أو بالنسبة للبرامج التي لا تعتمد على الذكاء الاصطناعي مثل خوادم الويب أو الواجهات الخلفية لـ CRUD أو البنية التحتية: تصف السمات الواثقة.* مكونات الذكاء الاصطناعي فقط.
