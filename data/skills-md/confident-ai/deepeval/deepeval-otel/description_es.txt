Exporte seguimientos sin procesar de OpenTelemetry desde una aplicación de IA al Observatorio de Confident AI. DISPARAR cuando el usuario desea enviar trazas/intervalos de OpenTelemetry u OTLP desde una aplicación LLM, un agente, una canalización RAG o un chatbot a Confident AI; configurar el punto final Confident AI OTLP; establezca los atributos confident.span.* o confident.trace.*; exportar rastros de aplicaciones de IA sin el paquete Python profundo; conectar un OTLPSpanExporter, OpenTelemetry Collector o un SDK de OTel independiente del proveedor a Confident AI; o elija el punto final OTLP de EE. UU. o UE. Independiente del idioma: el mecanismo son claves de atributos OTLP más un punto final exportador. NO DISPARE para crear suites de evaluación de pytest de DeepEval, conjuntos de datos, goldens, métricas o pruebas de ejecución de deepeval (use la habilidad `deepeval`); para instrumentar con el decorador @observe del SDK de DeepEval o integraciones de marco (use la habilidad `deepeval-tracing`); o para software que no es de IA, como servidores web, backends CRUD o infraestructura: los atributos confident.* describen únicamente los componentes de IA.
