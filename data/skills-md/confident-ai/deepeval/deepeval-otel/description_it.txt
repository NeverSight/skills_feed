Esporta tracce OpenTelemetry grezze da un'applicazione AI all'Osservatorio di Confident AI. TRIGGER quando l'utente desidera inviare tracce/span OpenTelemetry o OTLP da un'app LLM, un agente, una pipeline RAG o un chatbot a Confident AI; configurare l'endpoint Confident AI OTLP; impostare gli attributi confident.span.* o confident.trace.*; esportare tracce di app AI senza il pacchetto deepeval Python; collegare un OTLPSpanExporter, un OpenTelemetry Collector o un SDK OTel indipendente dal fornitore a Confident AI; oppure scegli l'endpoint OTLP USA vs UE. Indipendente dalla lingua: il meccanismo è costituito dalle chiavi degli attributi OTLP più un endpoint di esportazione. NON SI ATTIVA per la creazione di suite DeepEval pytest eval, set di dati, golden, metriche o esecuzione di test deepeval (usa l'abilità `deepeval`); per la strumentazione con il decoratore @observe dell'SDK DeepEval o le integrazioni del framework (utilizzare la competenza `deepeval-tracing`); o per software non AI come server Web, backend CRUD o infrastrutture: gli attributi confident.* descrivono solo i componenti AI.
