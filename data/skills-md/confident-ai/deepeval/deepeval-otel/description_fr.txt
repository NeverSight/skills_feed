Exportez les traces brutes d’OpenTelemetry d’une application d’IA vers l’observatoire de Confident AI. DÉCLENCHEMENT lorsque l'utilisateur souhaite envoyer des traces/spans OpenTelemetry ou OTLP à partir d'une application LLM, d'un agent, d'un pipeline RAG ou d'un chatbot à Confident AI ; configurer le point de terminaison Confident AI OTLP ; définir les attributs confiant.span.* ou confiant.trace.* ; exporter les traces d'applications IA sans le package Python deepeval ; câblez un SDK OTLPSpanExporter, OpenTelemetry Collector ou OTel indépendant du fournisseur à Confident AI ; ou choisissez le point de terminaison OTLP États-Unis vs UE. Indépendant de la langue : le mécanisme est constitué de clés d'attribut OTLP plus un point de terminaison d'exportateur. NE PAS DÉCLENCHER pour créer des suites d'évaluation pytest DeepEval, des ensembles de données, des goldens, des métriques ou des tests deepeval (utilisez la compétence « deepeval ») ; pour l'instrumentation avec le décorateur @observe ou les intégrations de framework du SDK DeepEval (utilisez la compétence « deepeval-tracing ») ; ou pour les logiciels non-IA tels que les serveurs Web, les backends CRUD ou l'infrastructure : les attributs confiant.* décrivent uniquement les composants d'IA.
