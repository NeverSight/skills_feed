Utilice un modelo de visión de terceros configurado para inspeccionar imágenes locales y devolver un contexto visual fundamentado que se puede proporcionar a DeepSeek. Utilice esta habilidad siempre que un flujo de trabajo de Codex + DeepSeek necesite comprensión de imágenes, OCR, respuesta visual a preguntas, descripción de imágenes o extracción estructurada de una imagen. Utilícelo también cuando el agente reconozca que necesita ver una imagen pero el mensaje la entrega como marcador de posición "[Imagen no admitida]". Trate ese marcador de posición como disparador para ejecutar el puente en la ruta de la imagen adjunta o en el portapapeles. Admite proveedores Qwen/DashScope y Gemini, selección de proveedores a través de config.json, claves API .env de raíz del proyecto, URL base configurables y nombres de modelos, y modo de pensamiento opcional.
