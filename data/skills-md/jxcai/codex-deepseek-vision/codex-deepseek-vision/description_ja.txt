構成されたサードパーティのビジョン モデルを使用してローカル画像を検査し、DeepSeek に提供できる根拠のあるビジュアル コンテキストを返します。 Codex + DeepSeek ワークフローで画像の理解、OCR、視覚的な質問応答、画像の説明、または画像からの構造化された抽出が必要な場合は、このスキルを常に使用してください。また、エージェントが画像を表示する必要があることを認識しているが、メッセージが画像をプレースホルダー `[Unsupported Image]` として配信する場合にも使用します。そのプレースホルダーを、添付された画像パスまたはクリップボードでブリッジを実行するトリガーとして扱います。 Qwen/DashScope および Gemini プロバイダー、config.json によるプロバイダーの選択、プロジェクト ルート .env API キー、構成可能なベース URL とモデル名、およびオプションの思考モードをサポートします。
