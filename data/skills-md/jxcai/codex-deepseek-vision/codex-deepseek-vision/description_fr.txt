Utilisez un modèle de vision tiers configuré pour inspecter les images locales et renvoyer un contexte visuel fondé qui peut être fourni à DeepSeek. Utilisez cette compétence chaque fois qu'un flux de travail Codex + DeepSeek nécessite une compréhension d'image, une OCR, une réponse visuelle à des questions, une description d'image ou une extraction structurée à partir d'une image. Utilisez-le également lorsque l'agent reconnaît qu'il a besoin d'afficher une image mais que le message la transmet comme espace réservé « [Image non prise en charge] » — traitez cet espace réservé comme le déclencheur pour exécuter le pont sur le chemin de l'image ou le presse-papiers attaché. Prend en charge les fournisseurs Qwen/DashScope et Gemini, la sélection des fournisseurs via config.json, les clés API .env racine du projet, les URL de base et les noms de modèles configurables et le mode de réflexion facultatif.
