하드 게이트를 사용하여 Red-Green-Refactor를 적용합니다. Red 단계는 어설션(구문/구성 아님)에서 반드시 실패해야 하는 실패한 테스트를 작성하고 진행하기 전에 테스트+실패를 표시하고 각 단계 후에 특정 파일(전체 제품군이 아님)에 대한 테스트를 실행합니다. Green 단계는 통과하기 위한 최소한의 코드를 작성하고 거기서 중지합니다. Refactor 단계는 각 미세 변경 후에 테스트를 실행하고 전체적으로 Green을 유지해야 합니다. 실패한 테스트 사례를 생성하고, 진행하기 전에 테스트 실패를 검증하고, 레드 단계 검사를 통과한 후 구현을 시작합니다. 사용자가 TDD 워크플로를 요청하거나, 테스트를 먼저 작성하도록 요청하거나, Red-Green-Refactor 방법론을 언급하거나, 트리거 단어(TDD, 테스트 우선, 테스트 게이트)를 사용할 때 사용합니다.
