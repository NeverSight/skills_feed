Обеспечивает красный-зеленый-рефакторинг с помощью жестких шлюзов: красная фаза записывает неудачный тест, который ДОЛЖЕН завершиться неудачей при утверждении (не синтаксисе/конфигурации) и представляет тест+сбой перед продолжением, запускает тесты для конкретного файла (не полного набора) после каждой фазы, зеленая фаза записывает минимальный код для прохождения и останавливается на этом, фаза рефакторинга запускает тест после каждого микроизменения и ДОЛЖНА оставаться зеленой на всем протяжении. Генерирует неудачные тестовые случаи, проверяет провал теста перед продолжением, контролирует реализацию после прохождения красных проверок. Используйте, когда пользователь запрашивает рабочий процесс TDD, просит сначала написать тесты, упоминает методологию Red-Green-Refactor или использует триггерные слова: TDD, тест-сначала, тестовый шлюз.
