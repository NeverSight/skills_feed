Стандартизирует процедуры проверки безопасности для кода Ruby, сопоставленного с OWASP Top 10: список разрешенных всех входных параметров перед обработкой, запрет интерполяции SQL (`#{}`), проверка отсутствия зафиксированных или зарегистрированных секретов, запуск `bundle exec Bundle-audit Check --update`, проверка на внедрение оболочки (`system()`, обратные кавычки, `exec()`) и отбрасывание ключей, подобных инструкциям (`prompt`, `instructions`) в полезных нагрузках JSON. Охватывает проверку входных данных, управление секретами и аудит зависимостей. Триггерные слова: проверка безопасности, проверка безопасности, код аудита, уязвимость безопасности, проверка секретов, OWASP.
