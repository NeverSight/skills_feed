Estandariza los procedimientos de revisión de seguridad para el código Ruby asignado a OWASP Top 10: incluir en la lista todos los parámetros de entrada antes del procesamiento, prohibir la interpolación SQL (`#{}`), verificar que no haya secretos confirmados o registrados, ejecutar `bundle exec bundle-audit check --update`, verificar si hay inyección de shell (`system()`, comillas invertidas, `exec()`) y descartar claves similares a instrucciones (`prompt`, `instructions`) en cargas útiles JSON. Cubre la validación de entradas, la gestión de secretos y las auditorías de dependencia. Palabras desencadenantes: revisión de seguridad, verificación de seguridad, código de auditoría, vulnerabilidad de seguridad, verificación de secretos, OWASP.
