Standardizza le procedure di revisione della sicurezza per codice Ruby mappato al OWASP Top 10: consenti in whitelist tutti i parametri di input prima dell’elaborazione, proibisci l’interpolazione SQL (`#{}`), verifica che non siano stati commessi o registrati segreti, esegui `bundle exec bundle-audit check --update`, controlla le iniezioni di shell (`system()`, backticks, `exec()`), e scarta chiavi simili a istruzioni (`prompt`, `instructions`) nei payload JSON. Copre la validazione dell’input, la gestione dei segreti e gli audit delle dipendenze. Parole chiave: revisione della sicurezza, controlla sicurezza, audit del codice, vulnerabilità di sicurezza, verifica dei segreti, OWASP.
