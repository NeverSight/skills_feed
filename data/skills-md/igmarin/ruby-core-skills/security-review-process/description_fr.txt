Standardise les procédures d'examen de sécurité pour le code Ruby mappé à OWASP Top 10 : autoriser tous les paramètres d'entrée avant le traitement, interdire l'interpolation SQL (`#{}`), vérifier qu'aucun secret n'est commis ou enregistré, exécuter `bundle exec bundle-audit check --update`, vérifier l'injection de shell (`system()`, backticks, `exec()`) et supprimer les clés de type instruction (`prompt`, `instructions`) dans les charges utiles JSON. Couvre la validation des entrées, la gestion des secrets et les audits de dépendances. Mots déclencheurs : examen de sécurité, vérification de la sécurité, code d'audit, vulnérabilité de sécurité, vérification des secrets, OWASP.
