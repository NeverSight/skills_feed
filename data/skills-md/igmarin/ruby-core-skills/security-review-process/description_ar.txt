توحيد إجراءات مراجعة الأمان لرمز Ruby المعين إلى OWASP Top 10: إدراج جميع معلمات الإدخال قبل المعالجة، ومنع استيفاء SQL (`#{}`)، والتحقق من عدم وجود أسرار ملتزمة أو مسجلة، وتشغيل `bundle exec Bundle-audit check --update`، والتحقق من حقن الصدفة (`system()`، وbackticks، و`exec()`)، وتجاهل المفاتيح المشابهة للتعليمات (`prompt`، `instructions`) في JSON الحمولات. يغطي التحقق من صحة المدخلات، وإدارة الأسرار، وتدقيق التبعية. الكلمات المثيرة للاهتمام: مراجعة الأمان، التحقق من الأمان، كود التدقيق، الثغرة الأمنية، فحص الأسرار، OWASP.
