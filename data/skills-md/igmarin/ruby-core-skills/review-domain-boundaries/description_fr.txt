À utiliser lors de l'examen d'une application Ruby pour les limites DDD (conception axée sur le domaine), les limites des modules, les limites des services ou l'organisation du code : détecte les contextes délimités, les fuites de langage, l'orchestration inter-contextes et la propriété peu claire - utilise `rg` pour trouver des références inter-contextes et des termes divulgués, identifie les modèles de domaine mal placés et documente la direction de propriété (quel contexte possède les invariants, les transitions et les effets secondaires), propose la plus petite amélioration crédible des limites avant de grandes réorganisations, produit d'abord les résultats, puis ouvre les questions. puis recommande les compétences suivantes et charge les exemples de fuites de limites uniquement lorsque leur contenu est nécessaire. Couvre le mappage de contexte, la détection de fuites et le couplage inter-contexte.
