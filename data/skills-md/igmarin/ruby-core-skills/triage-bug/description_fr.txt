À utiliser lors de l'enquête sur un bug, une erreur ou une régression dans une base de code Ruby ou Rails. Crée un test de reproduction défaillant, isole le chemin du code défectueux et produit un plan de correctif minimal. Mots déclencheurs : débogage, cassé, erreur, régression, trace de pile, échec du test, rapport de bug, bug Ruby, erreur Rails, fichier .rb cassé.
