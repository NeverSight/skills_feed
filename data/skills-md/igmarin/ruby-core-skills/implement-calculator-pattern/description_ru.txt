Используйте при построении калькуляторов на основе вариантов с маршрутизацией SERVICE_MAP через Factory.for(entity) (ТОЛЬКО разрешенная точка входа — прямое создание экземпляра ЗАПРЕЩЕНО), BaseService определяет `calculate`→`compute_result`, если `should_calculate?`, NullService имеет `should_calculate?`=false+`compute_result`=nil, Конкретные службы переопределяют оба метода и ДОЛЖНЫ вызывать `super` в `should_calculate?` — и каждый компонент тестируется по порядку (запись спецификации → запуск → проверка красного → реализация → запуск → проверка зеленого перед следующим компонентом, без сворачивания NullService и конкретного в один шаг). Тестовое покрытие включает в себя: именованные варианты, неактивный план, нулевой план и неизвестные контексты вариантов. Испытания каркасов для каждого варианта. Триггерные слова: шаблон стратегии, шаблон фабрики, шаблон нулевого объекта, калькулятор вариантов, таблица диспетчеризации, SERVICE_MAP, резервный вариант без операций.
