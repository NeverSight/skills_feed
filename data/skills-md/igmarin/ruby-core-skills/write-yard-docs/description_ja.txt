Ruby パブリック API の YARD ドキュメントを記述するときに使用します。すべてのパブリック メソッドには `@param`、`@return [Hash]`、および `@raise` タグが必要です。`#call` とは別に `self.call` を文書化し、独自の `@raise` タグで各例外をリストし、モジュールレベルの構造には `@example` を使用し、相互参照には `@see` を使用し、YARD `@return` 型の注釈規則に従い、明示的な YARD を追加します。実装後のサブタスクをタスク リストに追加し、別途要求がない限り、すべての YARD テキストを英語にし、「yard stats --list-undoc」を実行してカバレッジを確認し、特定のコンテンツが必要な場合にのみ拡張リソース ファイルをロードします。トリガーワード: YARD、インラインドキュメント、メソッドドキュメント、API ドキュメント、パブリックインターフェイス、Rdoc、リターンタグ、レイズタグ。
