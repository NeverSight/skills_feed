Используйте при написании документации YARD для общедоступных API Ruby: каждый общедоступный метод ДОЛЖЕН иметь теги `@param`, `@return [Hash]` и `@raise`, документируйте `self.call` отдельно от `#call`, перечисляйте каждое исключение с помощью собственного тега `@raise`, используйте `@example` для конструкций уровня модуля, `@see` для перекрестных ссылок, следуйте соглашениям об аннотациях типа YARD `@return`, добавляйте явный YARD подзадачи после реализации в списки задач, сохраняйте весь текст YARD на английском языке, если не требуется иное, запускайте `yard stats --list-undoc` для проверки покрытия и загружайте файлы расширенных ресурсов только тогда, когда их конкретное содержимое необходимо. Триггерные слова: YARD, встроенная документация, документация по методам, документация по API, общедоступный интерфейс, rdoc, тег возврата, тег повышения.
