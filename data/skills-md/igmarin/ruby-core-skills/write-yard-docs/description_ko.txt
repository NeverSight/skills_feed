Ruby 공개 API에 대한 YARD 문서를 작성할 때 사용: 모든 공개 메서드에는 반드시 `@param`, `@return [Hash]` 및 `@raise` 태그가 있어야 합니다. `#call`과 별도로 `self.call`을 문서화하고, 자체 `@raise` 태그로 각 예외를 나열하고, 모듈 수준 구성에는 `@example`을 사용하고, 상호 참조에는 `@see`를 사용하고, YARD `@return` 유형 주석 규칙을 따르고, 구현 후 작업 목록에 명시적인 YARD 하위 작업을 추가하고, 유지합니다. 달리 요청하지 않는 한 모든 YARD 텍스트는 영어로 되어 있으며 `yard stats --list-undoc`를 실행하여 적용 범위를 확인하고 특정 콘텐츠가 필요할 때만 확장 리소스 파일을 로드합니다. 트리거 단어: YARD, 인라인 문서, 메서드 문서, API 문서, 공개 인터페이스, rdoc, 반환 태그, 올리기 태그.
