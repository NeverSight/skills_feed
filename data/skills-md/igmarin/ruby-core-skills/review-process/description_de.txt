Überprüft PRs mithilfe strukturierter Ergebnisse mit Schweregraden (Kritisch/Major/Minor/Nitpick), überprüft, ob der Änderungssatz Tests auf neue/geänderte Logik enthält, prüft auf Korrektheit + Sicherheit + Einhaltung der Domänensprache, prüft auf Scope Creep und Autorisierungslücken (fehlende Prüfungen sind kritisch), präsentiert eine strukturierte Tabelle mit Ergebnissen nach Schweregrad, generiert Selbstüberprüfungs-Checklisten für Autoren, erstellt Ergebnisberichte, legt Kriterien für die erneute Überprüfung fest – und führt die Überprüfung der erneuten Überprüfung durch, indem der Unterschied gegeneinander überprüft wird finden. Verwenden Sie diese Option, wenn der Benutzer eine Codeüberprüfung anfordert, um die Überprüfung einer Pull-Anfrage bittet oder eine strukturierte Codeüberprüfung mit nach Schweregrad klassifizierten Ergebnissen benötigt. Auslösewörter: Codeüberprüfung, PR-Überprüfung, PR-Überprüfung, Codeprüfung, strukturierte Überprüfung, Schweregrade.
