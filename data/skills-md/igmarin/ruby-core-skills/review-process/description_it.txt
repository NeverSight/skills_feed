Revisiona le PR utilizzando risultati strutturati con livelli di gravità (Critico/Maggiore/Minore/Nitpick), verifica che il changeset includa test per la logica nuova o modificata, controlla correttezza, sicurezza, protezione e aderenza al linguaggio di dominio, individua eventuali scope creep e lacune di autorizzazione (i controlli mancanti sono Critici), presenta una tabella strutturata dei risultati per gravità, genera checklist di auto‑revisione per gli autori, produce rapporti dei risultati, determina i criteri per la ri‑revisione e ne esegue la verifica confrontando il diff con ciascun risultato. Da usare quando l’utente richiede una revisione del codice, chiede di revisionare una pull request o ha bisogno di un audit di codice strutturato con risultati classificati per gravità. Parole di attivazione: code review, review PR, PR review, code audit, structured review, severity levels.
