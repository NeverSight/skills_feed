Просматривает PR с использованием структурированных результатов с уровнями серьезности (Критический/Серьезный/Незначительный/Придирчивый), проверяет набор изменений, включающий тесты на новую/модифицированную логику, проверяет правильность + безопасность + безопасность + соответствие языку предметной области, проверяет расширение объема и пробелы в авторизации (отсутствующие проверки являются критическими), представляет структурированную таблицу результатов по серьезности, генерирует контрольные списки для самопроверки для авторов, составляет отчеты о результатах, определяет критерии повторной проверки и выполняет повторную проверку анализ различий по каждому выводу. Используйте, когда пользователь запрашивает проверку кода, просит просмотреть запрос на включение или нуждается в структурированном аудите кода с результатами, классифицированными по степени серьезности. Триггерные слова: проверка кода, проверка PR, проверка PR, аудит кода, структурированная проверка, уровни серьезности.
