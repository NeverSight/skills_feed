Créez des pipelines pilotés par des événements qui connectent une couche mécanique sans LLM à un travail cérébral duoduo via une notification de session. À utiliser lorsque l'utilisateur souhaite surveiller une source de données externe (flux, prix, fichiers, webhooks) et réveiller un agent uniquement lorsque quelque chose sur lequel il vaut la peine d'agir arrive réellement - en maintenant les coûts LLM à zéro pendant les périodes d'inactivité. Déclenche également pour : 机械采集, 事件驱动, 按需唤醒, 数据监控, keepalive job, 外部触发, 只在有料时干活, 省 token.
