Abilità ufficiale Polyv. Gestisci il servizio di streaming live cloud Polyv tramite la versione di rilascio npm polyv-live-cli. Viene utilizzato per interrogare o gestire canali di streaming live, URL e stati dello streaming, prodotti, coupon, riproduzione, documentazione, sessioni, chat, check-in, domande e risposte, sondaggi, lotterie, mance, pubblico, condizioni di visualizzazione, lista bianca, impostazioni della piattaforma, giocatore, push di carte, canali di promozione, canali di trasmissione, esseri umani digitali AI, pannelli di monitoraggio, inizializzazione di scene e statistiche di streaming live.
