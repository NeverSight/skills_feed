Compétence officielle Polyv. Gérez le service de diffusion en direct sur le cloud Polyv via la version npm polyv-live-cli. Il est utilisé pour interroger ou gérer les chaînes de diffusion en direct, les URL et les statuts de diffusion, les produits, les coupons, la lecture, la documentation, les sessions, le chat, l'enregistrement, les questions et réponses, les enquêtes, les loteries, les pourboires, les audiences, les conditions de visualisation, la liste blanche, les paramètres de la plate-forme, le lecteur, les poussées de cartes, les canaux de promotion, les canaux de relais, les humains numériques IA, les panneaux de surveillance, l'initialisation de scène et les statistiques de diffusion en direct.
