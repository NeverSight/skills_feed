Questa abilità dovrebbe essere utilizzata per comprendere la struttura del codice, trovare dipendenze tra funzioni/classi, tracciare i grafici delle chiamate o esplorare le relazioni del codice. Le frasi trigger includono "grafico del codice", "grafico delle chiamate", "chi chiama", "che cosa chiama", "trova dipendenze", "struttura del codice", "ereditarietà", "trova percorsi".
