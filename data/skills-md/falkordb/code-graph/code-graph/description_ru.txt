Этот навык следует использовать при понимании структуры кода, поиске зависимостей между функциями/классами, отслеживании графов вызовов или изучении взаимосвязей кода. Триггерные фразы включают «график кода», «график вызовов», «кто звонит», «что звонит», «найти зависимости», «структуру кода», «наследование», «найти пути».
