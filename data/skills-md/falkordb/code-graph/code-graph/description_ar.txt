يجب استخدام هذه المهارة عند فهم بنية التعليمات البرمجية، أو العثور على التبعيات بين الوظائف/الفئات، أو تتبع الرسوم البيانية للاتصال، أو استكشاف علاقات التعليمات البرمجية. تتضمن عبارات التشغيل "الرسم البياني للكود" و"الرسم البياني للاتصال" و"من يتصل" و"ماذا يتصل" و"البحث عن التبعيات" و"بنية التعليمات البرمجية" و"الميراث" و"البحث عن المسارات".
