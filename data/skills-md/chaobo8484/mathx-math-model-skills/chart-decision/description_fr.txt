Sélectionnez le type de graphique en fonction du type de données et de l'objectif de communication, et éliminez les encodages trompeurs. Utilisez-le lorsque vous disposez de données mais que vous n’avez pas décidé d’un type de graphique ; lorsque le type de graphique est déjà déterminé, procédez directement aux techniques de traçage correspondantes.
