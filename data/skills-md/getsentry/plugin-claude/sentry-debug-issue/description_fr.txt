Déboguez et corrigez un problème Sentry — recherchez-le (par lien, ID ou recherche), extrayez le contexte complet (trace de pile, fil d'Ariane, trace, journaux), exécutez éventuellement la cause première/correction automatique de Seer, appliquez le correctif de code et résolvez-le via un commit/PR `Fixes PROJECT-NAME-12A`. À utiliser lorsque vous travaillez sur une erreur connue ou que vous en recherchez une pour la corriger.
