Élaborez et enregistrez les décisions d'architecture qui maintiennent la cohérence des parties construites séparément d'un système, dans un court document d'architecture. Crée, met à jour ou valide un ; fonctionne à partir d'une spécification, d'une idée brute ou d'une base de code existante. À utiliser lorsque l'utilisateur dit « créer l'architecture », « créer une architecture technique », « la structure de l'architecture » ou « créer une conception de solution ».
