Führt eine oder mehrere installierte Überprüfungslinsen durch – kontradiktorische Kritik, Randfälle, Verifizierungslücken, Struktur, Prosa – und meldet selektierte Ergebnisse. Verwenden Sie dies nur dann, wenn der Benutzer Sie auffordert, ein Diff, eine Pull-Anfrage oder ein Artefakt zu überprüfen – Code oder Dokumente, eines oder mehrere – und tatsächlich „Überprüfen“ sagt; Eine explizite „skill:bmad-review“-Anweisung eines anderen Skills gilt als diese Anfrage. Eine Aufforderung, auf das Feedback einer früheren Überprüfung zu reagieren, ist eine Änderung, keine Überprüfung. Rufen Sie dies niemals unaufgefordert auf, auch nicht bei Änderungen, die Sie gerade vorgenommen haben.
