意思決定をサポートするトピックを調査します。次の 3 つの方法があります。ユーザーが独自のツール (ChatGPT、Gemini、Grok、Perplexity など) で実行できる調査プロンプトを下書きする、完成した調査レポートを他のスキルが直接使用できる引用ソースを含む短い概要に変換する、または並行 Web 検索を使用してここで調査を実行する。組み込みの調査タイプ: 市場、ドメイン、技術、競合、ユーザーの声、学術的研究。候補からの選択や、オーバーライドによるカスタム タイプもサポートしています。ユーザーが「詳細な調査」、「これを調査する」、「調査プロンプトを作成する」、「この調査レポートを処理する」、「市場調査」、「ドメイン調査」、「技術調査」、「競合他社の調査」、「文献レビュー」、または「選択を手伝ってください」と言うときに使用します。
