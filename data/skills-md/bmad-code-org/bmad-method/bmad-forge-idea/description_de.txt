Testen Sie eine halbfertige Idee in einem Fragegespräch, wobei verschiedene Personen ihre Schwachstellen sondieren, bis der Benutzer darauf reagieren oder sie mit Zuversicht fallen lassen kann. Verfasst optional eine kurze Zusammenfassung der Planungsfähigkeiten, auf denen Sie aufbauen können. Wird verwendet, wenn der Benutzer sagt: „Eine Idee schmieden“, „Diese Idee einem Drucktest unterziehen“, „Mein Denken einem Stresstest unterziehen“ oder „Diese Idee festigen“.
