Explorez et comprenez les bases de code à l'aide de la recherche sémantique SocratiCode, des graphiques de dépendances et des artefacts de contexte. À utiliser pour explorer le code, comprendre l'architecture, rechercher des fonctions/types, analyser les dépendances, rechercher des schémas de base de données ou des spécifications d'API, ou lorsque des outils socraticode/codebase_search sont disponibles. S'active lorsque l'utilisateur pose des questions sur la structure du code, souhaite savoir où se trouve une fonctionnalité ou a besoin de comprendre comment le code est organisé.
