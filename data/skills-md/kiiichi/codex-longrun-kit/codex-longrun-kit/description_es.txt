Inicialice un repositorio para el trabajo del Codex compacto y revisable de larga duración mediante la creación de un contrato de tarea, un plan de hitos, una instantánea del estado, reglas de detención, puertas de validación y un flujo de trabajo de revisión diferida. Úselo cuando el usuario desee una tarea de implementación, migración, refactorización o codificación autónoma revisable de varias horas; no lo utilice para pequeñas ediciones de una sola vez.
