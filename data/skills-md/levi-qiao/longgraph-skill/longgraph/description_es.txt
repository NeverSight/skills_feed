Enrute y cree ejecuciones duraderas de gráficos de bucle de largo horizonte. Úselo para trabajos de múltiples rondas que necesitan un estado duradero, hitos cerrados, límites de propietario, cambio de host o auditoría independiente. Limpieza de código de ruta a /loop-converge, requisitos de funciones a /loop-deliver y comparación de soluciones respaldadas por evidencia con /loop-research; use loop-graph directamente solo para una forma de ejecución personalizada. Para una tarea autónoma, recomiende directamente la tarea u objetivo ordinario del anfitrión. No ejecute ni reanude archivos de nodo de tiempo de ejecución generados.
