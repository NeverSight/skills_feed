Gestisci e genera file .gitignore utilizzando la libreria di modelli gitignore ufficiale di GitHub tramite la CLI `ign`. Da utilizzare durante l'inizializzazione di nuovi repository di progetto, il rilevamento automatico dello stack di progetti dai file, l'aggiunta di regole di ignoranza di lingua/framework/IDE, l'ispezione dei modelli applicati o la modifica sicura di file .gitignore esistenti.
