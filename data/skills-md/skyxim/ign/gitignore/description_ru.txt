Управляйте файлами .gitignore и генерируйте их с помощью официальной библиотеки шаблонов gitignore GitHub через интерфейс командной строки `ign`. Используйте при инициализации новых репозиториев проектов, автоматическом обнаружении стека проекта из файлов, добавлении правил игнорирования языка/фреймворка/IDE, проверке примененных шаблонов или безопасном изменении существующих файлов .gitignore.
