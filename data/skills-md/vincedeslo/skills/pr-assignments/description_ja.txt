過去 2 週間に認証されたユーザーからレビューが要求された、開いている GitHub プル リクエストをすべてクロールし、それぞれを 1 行に要約し、コメントの会話を要約して、レビュー SLA の有効期限順にランク付けします (未レビューと最も期限を過ぎたものから順)。再起動でクリアされた一時ディレクトリ内の自己完結型 HTML レポートとして、直接リクエスト、次にチーム リクエストに分割されます。厳密に読み取り専用であり、GitHub CLI は読み取り専用です。どの PR が自分に割り当てられているのか、レビューで何が待機しているのかを尋ねられた場合、レビュー キューまたはレビュー バックログを優先順位付けするために、またはユーザーが「PR 割り当て」と答えた場合に使用します。
