قم بتدقيق مستودع الخدمة وإنتاج بطاقة تقرير HTML قابلة للمشاركة وتصنيفها من A إلى F عبر 23 جانبًا - الازدواجية المنطقية، والطبقات، واكتمال واجهة برمجة التطبيقات (API) وأمانها، وعقود الأحداث، والتخزين، والنشر، وقابلية الملاحظة، والاقتران، وجهود الصيانة، واتساق التسمية، والاختبارات، ومعالجة الأخطاء، والتبعيات، والتعليمات البرمجية الميتة، وتعفن التوثيق، والتكوين والأسرار، وتجربة التطوير المحلية، وإصدار واجهة برمجة التطبيقات (API)، وحدود المجال، وترحيل البيانات، وشكل الأداء، وإمكانية التنقل في الريبو - كل منها مع الجزء العلوي 3 طرق للتحسين. يُستخدم عندما يُطلب منك تسجيل أو تقدير أو تدقيق أو تقييم أو مراجعة الجودة أو الصحة أو قابلية الصيانة لخدمة أو قاعدة التعليمات البرمجية، أو عندما يقول المستخدم "بطاقة أداء الخدمة".
