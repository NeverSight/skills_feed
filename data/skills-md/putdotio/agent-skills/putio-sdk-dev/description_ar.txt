قم بتطوير أو مراجعة كود عميل SDK وAPI المملوك لشركة put.io عبر TypeScript وSwift وKotlin والحزم المشابهة. يُستخدم فقط للعمل في مستودع put.io SDK أو الطلبات الصريحة لاتفاقيات put.io SDK. لا تستخدمه مع حزم SDK غير ذات صلة، أو فحص put.io للمتصفح فقط، أو رمز تطبيق المستخدم النهائي، أو عمليات putio CLI.
