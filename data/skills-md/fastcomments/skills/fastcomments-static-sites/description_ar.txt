يُستخدم عند إضافة تعليقات إلى موقع ثابت أو مدونة تم إنشاؤها باستخدام Astro أو Hugo أو Jekyll أو Eleventy (11ty) أو Docusaurus أو Gatsby، حيث لا توجد واجهة خلفية لتخزين التعليقات. يغطي مكون سمة FastComments، والمكون الإضافي، والعلامة لكل منشئ، وتعيين معرف المستأجر مرة واحدة في تكوين الموقع، واختيار معرف url ثابت لكل مشاركة حتى تنجو سلاسل الرسائل من تغييرات عنوان URL، وإظهار عدد التعليقات في فهرس المدونة مع طلب مجمع واحد، والاحتياطي بدون JavaScript. بالنسبة إلى React وNext.js، راجع fastcomments-react-nextjs.
