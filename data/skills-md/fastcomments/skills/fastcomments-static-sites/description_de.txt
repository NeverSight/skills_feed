Verwenden Sie diese Option, wenn Sie Kommentare zu einer statischen Website oder einem Blog hinzufügen, die mit Astro, Hugo, Jekyll, Eleventy (11ty), Docusaurus oder Gatsby erstellt wurde und kein Backend zum Speichern von Kommentaren vorhanden ist. Behandelt die FastComments-Designkomponente, das Plugin und das Tag für jeden Generator, das einmalige Festlegen der Mandanten-ID in der Site-Konfiguration, das Auswählen einer stabilen URL-ID pro Beitrag, damit Threads URL-Änderungen überstehen, das Anzeigen der Kommentaranzahl in einem Blog-Index mit einer Massenanforderung und den Fallback ohne JavaScript. Für React und Next.js siehe fastcomments-react-nextjs.
