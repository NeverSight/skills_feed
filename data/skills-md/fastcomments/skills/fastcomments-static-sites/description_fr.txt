À utiliser lors de l'ajout de commentaires à un site ou un blog statique créé avec Astro, Hugo, Jekyll, Eleventy (11ty), Docusaurus ou Gatsby, où il n'y a pas de backend pour stocker les commentaires. Couvre le composant de thème FastComments, le plugin et la balise pour chaque générateur, définissant l'ID du locataire une fois dans la configuration du site, choisissant un urlId stable par publication afin que les fils de discussion survivent aux modifications d'URL, affichant le nombre de commentaires sur un index de blog avec une requête groupée et la solution de secours sans JavaScript. Pour React et Next.js, voir fastcomments-react-nextjs.
