Используйте при добавлении комментариев на статический сайт или блог, созданный с помощью Astro, Hugo, Jekyll, Eleventy (11ty), Docusaurus или Gatsby, где нет серверной части для хранения комментариев. Охватывает компонент темы FastComments, плагин и тег для каждого генератора, устанавливает идентификатор клиента один раз в конфигурации сайта, выбирает стабильный URL-адрес для каждого сообщения, чтобы потоки выдерживали изменения URL-адреса, показывает количество комментариев в индексе блога с помощью одного массового запроса и резервного варианта без JavaScript. Для React и Next.js см. fastcomments-react-nextjs.
