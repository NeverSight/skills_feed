Úselo cuando agregue comentarios a un sitio estático o blog creado con Astro, Hugo, Jekyll, Eleventy (11ty), Docusaurus o Gatsby, donde no hay un backend para almacenar comentarios. Cubre el componente del tema FastComments, el complemento y la etiqueta para cada generador, configurando el ID del inquilino una vez en la configuración del sitio, seleccionando un URLId estable por publicación para que los hilos sobrevivan a los cambios de URL, mostrando el recuento de comentarios en un índice de blog con una solicitud masiva y la alternativa sin JavaScript. Para React y Next.js, consulte fastcomments-react-nextjs.
