Erstellen Sie ein neues Dashboard oder aktualisieren Sie ein vorhandenes anhand einer Reihe von Erkenntnissen – die gleiche Aufgabe, die der In-App-Assistent mit seinem Upsert-Dashboard-Tool erledigt, jedoch über MCP. Verwenden Sie diese Option, wenn ein Benutzer ein Dashboard erstellen, mehrere Metriken/Diagramme auf einer Seite zusammenfassen, ein Dashboard für ein Thema (Produktanalyse, Kundenbindung, Umsatz, Aktivierung usw.) zusammenstellen oder Erkenntnisse zu einem bereits vorhandenen Dashboard hinzufügen/entfernen/ersetzen möchte. Behandelt die Entscheidung zwischen Erstellen und Aktualisieren, die Wiederverwendung vorhandener Erkenntnisse statt der Erstellung neuer Erkenntnisse und die Verwendung der geprüften Dashboard-Vorlagen von PostHog als Referenz dafür, wie ein starkes Dashboard zu einem Thema aussieht.
