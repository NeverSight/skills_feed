Direkte „useEffect“-Aufrufe von React erkennen, ersetzen und mechanisch einschränken. Wird beim Schreiben, Refactoring, Überprüfen oder Migrieren von React-Code verwendet, der den Status abruft, ableitet, Ereignisse weiterleitet, den Status zurücksetzt oder durch Effekte synchronisiert. Nicht für unabhängige React-Arbeiten oder Nicht-React-Effektsysteme verwenden.
