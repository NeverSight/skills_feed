Détectez, remplacez et limitez mécaniquement les appels directs « useEffect » de React. À utiliser lors de l'écriture, de la refactorisation, de la révision ou de la migration du code React qui récupère, dérive l'état, relaie les événements, réinitialise l'état ou se synchronise via des effets. Ne pas utiliser pour des travaux React non liés ou des systèmes d’effets non React.
