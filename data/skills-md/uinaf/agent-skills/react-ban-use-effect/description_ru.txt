Обнаруживайте, заменяйте и механически ограничивайте прямые вызовы React useEffect. Используйте при написании, рефакторинге, проверке или миграции кода React, который извлекает, извлекает состояние, передает события, сбрасывает состояние или синхронизируется с помощью эффектов. Не используйте для несвязанной работы с React или систем эффектов, не связанных с React.
