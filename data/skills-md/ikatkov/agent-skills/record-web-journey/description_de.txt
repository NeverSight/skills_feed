Zeichnen Sie eine Webreise als Beweis auf dem Browser-Host auf – ein WebM-Video, einen Screenshot nach jedem Klick und jedem Seitenladen mit einer roten Markierung am Klickpunkt und einsteps.md-Protokoll. Funktioniert auf zwei Arten: Ein Agent steuert den Browser selbst über Agent-Browser über CDP, oder ein Mensch klickt durch ein von Playwright gestartetes Fenster, während das Skript aufzeichnet. Verwenden Sie diese Option, wenn Sie aufgefordert werden, „eine Webreise aufzuzeichnen“, „den Ablauf aufzuzeichnen“, „einen Benutzerablauf zu erfassen“, „mir zu zeigen, was Sie angeklickt haben“ oder wenn für eine exemplarische Vorgehensweise Screenshots und Videos als Beweis benötigt werden.
