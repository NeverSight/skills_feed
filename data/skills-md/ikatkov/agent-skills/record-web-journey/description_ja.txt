Web ジャーニーを証拠としてブラウザー ホストに記録します。WebM ビデオ、クリックするたびにスクリーンショットが表示され、クリック ポイントに赤いマーカーが表示されたページが読み込まれ、steps.md ログが記録されます。 2 つの方法で動作します。エージェントが CDP 経由でエージェント ブラウザーを介してブラウザー自体を駆動するか、スクリプトの記録中に人間が Playwright によって起動されたウィンドウをクリックして操作します。 「Web ジャーニーを記録する」、「フローを記録する」、「ユーザー フローをキャプチャする」、「クリックした内容を表示する」、またはウォークスルーで証拠としてスクリーンショットとビデオが必要な場合に使用します。
