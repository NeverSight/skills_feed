Enregistrez un parcours Web comme preuve sur l'hôte du navigateur : une vidéo WebM, une capture d'écran après chaque clic et chargement de page avec un marqueur rouge au point de clic et un journal steps.md. Fonctionne de deux manières : un agent pilote le navigateur lui-même via le navigateur d'agent via CDP, ou un humain clique dans une fenêtre lancée par Playwright pendant que le script enregistre. À utiliser lorsqu'on vous demande « d'enregistrer un parcours Web », « d'enregistrer le flux », de « capturer un flux d'utilisateur », de « me montrer sur quoi vous avez cliqué » ou lorsqu'une visite guidée nécessite des captures d'écran et une vidéo comme preuve.
