Registre un viaje web como evidencia en el host del navegador: un video WebM, una captura de pantalla después de cada clic y cada carga de página con un marcador rojo en el punto de clic y un registro de pasos.md. Funciona de dos maneras: un agente maneja el navegador a través del navegador-agente a través de CDP, o un humano hace clic en una ventana iniciada por Playwright mientras el script graba. Úselo cuando se le solicite "grabar un recorrido web", "grabar el flujo", "capturar el flujo de un usuario", "muéstreme en qué hizo clic" o cuando un recorrido necesite capturas de pantalla y videos como prueba.
