Asesoramiento de agentes para la generación de activos para proyectos de desarrollo de juegos. Usa esta habilidad cuando estés desarrollando juegos y es posible que necesites generar imágenes, texturas, modelos 3D, efectos de sonido, música, etc. para el juego en el que estás trabajando. Úsalo incluso si solo planeas hacer una de estas cosas.
