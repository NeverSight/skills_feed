Консультации агента по созданию ресурсов для проектов разработки игр. Используйте этот навык, когда вы занимаетесь разработкой игр и вам может понадобиться создавать изображения, текстуры, 3D-модели, звуковые эффекты, музыку и т. д. для игры, над которой вы работаете. Используйте его, даже если вы только планируете сделать одну из этих вещей.
