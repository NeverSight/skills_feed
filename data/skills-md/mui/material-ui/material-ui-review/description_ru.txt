Просмотрите текущие различия на предмет регрессий, ошибок корректности, тестов, упрощений и проблем с документацией, масштабируя глубину до низкого/среднего/высокого/высокого/максимального уровня усилий. Используйте ТОЛЬКО при явном запросе по имени: пользователь запускает /material-ui-review, пишет $material-ui-review или запрашивает «навык проверки пользовательского интерфейса Material». НЕ используйте для общих запросов на проверку, таких как «просмотрите мои изменения», «просмотрите эту разницу/ветку/PR» или после завершения реализации — обрабатывайте запросы без этого навыка, если только пользователь не назовет его. Передайте --comment, чтобы опубликовать PR-комментарий верхнего уровня, --comment inline для встроенных PR-комментариев или --fix, чтобы применить полученные результаты.
