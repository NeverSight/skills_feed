Examinez la différence actuelle pour les régressions, les bogues d'exactitude, les tests, les simplifications et les problèmes de documentation, en mettant la profondeur à l'échelle à un niveau d'effort faible/moyen/élevé/xélevé/max. À utiliser UNIQUEMENT lorsque le nom le demande explicitement : l'utilisateur exécute /material-ui-review, écrit $material-ui-review ou demande "la compétence de révision Material UI". Ne PAS utiliser pour des demandes de révision générales telles que « réviser mes modifications », « réviser cette différence/branche/PR » ou après avoir terminé une implémentation – gérez celles qui n'ont pas cette compétence à moins que l'utilisateur ne la nomme. Passez --comment pour publier un commentaire PR de niveau supérieur, --comment inline pour les commentaires PR en ligne, ou --fix pour appliquer les résultats.
