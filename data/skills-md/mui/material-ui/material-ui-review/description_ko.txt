회귀, 정확성 버그, 테스트, 단순화 및 문서 문제에 대한 현재 차이점을 검토하고 깊이를 낮음/중간/높음/x높음/최대 노력 수준으로 조정합니다. 이름으로 명시적으로 요청한 경우에만 사용합니다. 사용자가 /material-ui-review를 실행하거나 $material-ui-review를 작성하거나 '머티리얼 UI 검토 기술'을 요청합니다. "내 변경 사항 검토", "이 차이점/분기/PR 검토"와 같은 일반적인 검토 요청이나 구현 완료 후 사용하지 마십시오. 사용자가 이름을 지정하지 않는 한 이 기술 없이 처리하십시오. 최상위 PR 댓글을 게시하려면 --comment를 전달하고, 인라인 PR 댓글을 게시하려면 --comment inline을 전달하고, 결과를 적용하려면 --fix를 전달합니다.
