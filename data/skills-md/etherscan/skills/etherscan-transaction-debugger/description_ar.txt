قم بتحليل وشرح واحدة أو اثنتين من معاملات EVM باستخدام بيانات Etherscan المباشرة وروابط أدلة Etherscan التي يمكن التحقق منها بواسطة الإنسان. يُستخدم عندما يقدم المستخدم تجزئة معاملة أو يسأل عما حدث، أو سبب فشل المعاملة، أو العقود أو المكالمات الداخلية التي تم تضمينها، أو مكان نقل الأصول، أو ما إذا تم تنفيذ تنفيذ الوكيل، أو المكالمة التي تم إرجاعها، أو لماذا تصرفت معاملتان بشكل مختلف. إعادة بناء مسار التنفيذ المدعوم، وفك تشفير المكالمات والأحداث، وتلخيص تغييرات الأصول والأذونات، وعرض معاملة Etherscan ذات الصلة، والعقد، والرمز المميز، والتسمية، والسجل، وطرق عرض المعاملات الداخلية، وتقديم تفسيرات باللغة الإنجليزية البسيطة أو المطور أو الدعم أو التفسيرات التي تركز على الأمان بثقة وقيود. لا تستخدمه لإجراء تحقيقات واسعة النطاق في المحفظة، أو آثار غسيل الأموال متعددة المراحل، أو عمليات تدقيق العقود الكاملة.
