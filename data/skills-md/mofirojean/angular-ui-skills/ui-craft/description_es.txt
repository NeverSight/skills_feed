Calidad transversal de la UI y habilidad en diseño de paneles. Cubre los tres indicadores de un panel amateur (los datos modelan la UI, divulgación progresiva, UI oculta), además de los principios de Refactoring UI (jerarquía, espaciado, tipografía, color, profundidad, retoques finales) y cómo aplicar cada uno en proyectos Angular usando Spartan/ng, PrimeNG, NG-ZORRO o Angular Material. Úsalo cuando el usuario solicite pulir, refinar, rediseñar o “hacer que esto se vea mejor”; al construir un panel, tabla, superficie de KPI o vista con muchos datos; cuando el proyecto tenga problemas de calidad visual (baja jerarquía, espaciado ambiguo, texto gris sobre color, color usado como única señal); o cuando el usuario mencione jerarquía, densidad, espaciado, tipografía, paleta, sombras o estados vacíos. Se combina con una de las habilidades específicas de la librería (spartan-ng-developer, primeng-developer, ng-zorro-developer, angular-material-developer) para la capa de implementación, y con angular-developer para los fundamentos de Angular.
