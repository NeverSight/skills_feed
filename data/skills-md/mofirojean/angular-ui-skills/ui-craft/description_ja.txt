横断的な UI 品質とダッシュボード設計スキル。アマチュア ダッシュボードの 3 つの要素 (UI を形成するデータ、プログレッシブ公開、非表示の UI) に加えて、リファクタリング UI 原則 (階層、間隔、タイポグラフィ、色、深さ、仕上げ)、および Spartan/ng、PrimeNG、NG-ZORRO、または Angular マテリアルを使用して Angular プロジェクトにそれぞれを適用する方法について説明します。ユーザーが磨きをかけ、改良し、再設計し、または「見栄えをよくしたい」と要求する場合に使用します。ダッシュボード、テーブル、KPI サーフェス、またはデータ量の多いビューを構築する場合。プロジェクトに視覚的な品質の問題がある場合（階層が低い、あいまいな間隔、色の上にグレーのテキスト、色が唯一の信号として使用されている）。または、ユーザーが階層、密度、間隔、タイポグラフィ、パレット、シャドウ、または空の状態について言及したとき。実装面についてはライブラリ固有のスキル (spartan-ng-developer、primeng-developer、ng-zorro-developer、angular-material-developer) のいずれかと組み合わせ、Angular の基礎については angular-developer と組み合わせます。
