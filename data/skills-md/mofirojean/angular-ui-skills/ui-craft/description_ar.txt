جودة واجهة المستخدم الشاملة ومهارة تصميم لوحة القيادة. يغطي القصص الثلاثة للوحة معلومات الهواة (تشكل البيانات واجهة المستخدم، والكشف التدريجي، وواجهة المستخدم المخفية)، بالإضافة إلى مبادئ إعادة هيكلة واجهة المستخدم (التسلسل الهرمي، والتباعد، والطباعة، واللون، والعمق، واللمسات النهائية) وكيفية تطبيق كل منها في مشاريع Angular باستخدام Spartan/ng، أو PrimeNG، أو NG-ZORRO، أو Angular Material. يُستخدم عندما يطلب المستخدم تلميعه أو تحسينه أو إعادة تصميمه أو "جعله يبدو أفضل"؛ عند إنشاء لوحة معلومات، أو جدول، أو سطح مؤشرات الأداء الرئيسية، أو طريقة عرض كثيفة البيانات؛ عندما يواجه المشروع مشكلات في الجودة المرئية (التسلسل الهرمي المنخفض، والتباعد الغامض، والنص باللون الرمادي، واللون المستخدم كإشارة وحيدة)؛ أو عندما يذكر المستخدم التسلسل الهرمي أو الكثافة أو التباعد أو الطباعة أو اللوحة أو الظلال أو الحالات الفارغة. يقترن بإحدى المهارات الخاصة بالمكتبة (spartan-ng-developer، وprimeng-developer، وng-zorro-developer، وangular-material-developer) لسطح التنفيذ، ومع المطور الزاوي للأساسيات الزاويّة.
