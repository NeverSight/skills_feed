Manipolazione di app native macOS prive di API preservando prove forensi riproducibili: cattura una finestra specifica (anche se è coperta in background), fai clic e inserisci, rileva se una particolare app può essere automatizzata, controlla le app integrate in Chromium tramite la manipolazione CDP zero-focus, esegui test di prodotto ed elaborazione batch multi-modello. Le attività relative al browser passano attraverso huashu‑chrome e la gestione dei vecchi screenshot passa attraverso disk‑keeper.
