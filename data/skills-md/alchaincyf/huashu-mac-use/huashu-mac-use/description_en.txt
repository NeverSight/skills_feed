Manipulating macOS native apps that lack an API while preserving reproducible forensic evidence: capture a specific window (even if it’s covered in the background), click and input, detect whether a particular app can be automated, control Chromium‑embedded apps via CDP zero‑focus manipulation, perform product testing and multi‑model batch processing. Browser‑related tasks go through huashu‑chrome, and handling old screenshots goes through disk‑keeper.
